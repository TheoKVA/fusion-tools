How it works

X

This tool converts a DaVinci Resolve Fusion macro (.setting) into a .drfx package. This helps for all the manual steps of packaging the code and the assets. without the need to manually change the .setting file.

Make sure this .html is executed locally (assets gathering will fail for security reasons).

1. Export your macro

Select all the nodes and leave all outputs checked. (the packager will clean up the outputs and redirect the final output to the node connected to the MediaOut node)

Save your macro as a .setting file.

Do not include the show name in the filename, as the packager adds it automatically.

Show Setting file Resulting DRFX file
"Vraiment" synthe-nom.setting Vraiment_SYNTHE-NOM.drfx ✅
"Vraiment" Vraiment-synthe-nom.setting Vraiment_VRAIMENT-SYNTHE-NOM.drfx 😱

2. Check external assets

When asked, select the folder containing the referenced assets. You can select a parent folder; the packager will scan it and its subfolders for matching PNG files.

3. Optional preview image

You can provide a PNG preview image for the template. The packager resizes it to 104 pixels wide while preserving its aspect ratio, then includes it in the package.

Understand what the packager does.

  • Renames the macro's internal tool identifier to match the generated template name.
  • Rewrites recognized external asset paths to use the package's asset folder.
  • Cleans up the macro's outputs.
  • Organizes the macro and its assets into the .drfx package structure.
  • Includes the optional preview image, if provided.
