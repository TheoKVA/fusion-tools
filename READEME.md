# Fusion Tools

A collection of utilities and snippets for DaVinci Resolve Fusion.
Developped @ RTS - Radio Television Suisse

## Available Tools

### 📋 Lua Clipboard Browser

Browse and instantly copy Lua snippets to the clipboard.

Features:

- Favorites
- Spotlight search (`Ctrl+Space`, `Cmd+Space`, `Shift+Space`)
- Keyboard navigation
- Recent history
- Automatic tool categorization

### 📦 DRFX Packager

Utility for creating and packaging Fusion `.drfx` archives.

### 🔧 CTRL Generator

Generate Fusion `CTRL` and `CTRL_OUT` nodes
